# Behind Documentation

The documentation is available in multiple languages. Every language has its own folder named after its locale (the same names as the frontend locale files), with the same structure inside.

| Language | Folder | Developer documentation | User manual |
|----------|--------|-------------------------|-------------|
| English | [en-US](./en-US/README.md) | [Developer documentation](./en-US/developer/README.md) | [User manual](./en-US/user-manual/README.md) |
| Magyar (Hungarian) | [hu-HU](./hu-HU/README.md) | [Fejlesztői dokumentáció](./hu-HU/developer/README.md) | [Felhasználói kézikönyv](./hu-HU/user-manual/README.md) |

## Adding a language

1. Copy the `en-US` folder to a new folder named after the locale (for example `de-DE`).
2. Translate every file, keeping the file names, the folder structure and the relative links.
3. Add the language to the table above.
